# VibeTalent social preview assets

The default link image is `/og-image-v3.jpg` (1200 × 630). It appears in Open Graph and Twitter card metadata on general site pages, including the home page. Telegram, Discord, WhatsApp, Facebook, and Reddit can use this image when they unfurl a site URL. Builder profiles and achievement pages keep their own specific preview images.

The matching files `/social-vibetalent-square-v3.jpg` (1080 × 1080) and `/social-vibetalent-portrait-v3.jpg` (1080 × 1350) are for direct social posts. Use the portrait image for an Instagram feed post. Instagram posts do not use the website's link preview automatically.

The new filename separates this image from the previous cached asset. Social platforms may also cache the page URL. If a shared link still shows the previous image, request a fresh scrape in that platform's link debugger or share a URL with a new query parameter after the deployment is live.
